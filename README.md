# Four Corner

> Search verified homes through your AI assistant via MCP.

Four Corner is an MCP (Model Context Protocol) server that connects your AI assistant directly to verified developer records, architectural blueprints, live rush-hour commute data, and true carpet areas in Hyderabad.

## Features

- **Direct MCP Integration**: Connect directly from Claude Desktop, ChatGPT, Cursor, and custom agent workflows.
- **100% RERA Verified**: Ingests data directly from official government RERA filings and builder ERP records.
- **Zero Brokers**: Search properties to your exact criteria with zero spam, zero markups, and zero commission-driven filtering.
- **Interactive 3D Visual Experience**: Scroll-driven interactive canvas frame animation demonstrating property inspection.
- **Responsive Architecture**: Fully responsive across mobile, tablet, and desktop devices.

## Local Development

Start a local HTTP server:

```bash
python3 -m http.server 3333
```

Open `http://localhost:3333/index.html` in your browser.
